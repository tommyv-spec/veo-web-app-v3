The Full Workflow
1

Upload Images

Drag photos into the upload area. One image = Single Mode (same photo every clip). Two or more = Multi-Image Mode, which unlocks Auto-Cycle and Storyboard.

📷 PNG / JPG / WebP 📷 Front-facing works best ☀️ Good lighting
2

Configure Settings

Set language, duration, aspect ratio, resolution. Use 8s + Interpolation ON for the best results. 1080p requires 8s.

⏳ 8s recommended 🌟 Interpolation ON 🌐 EN / IT / ES / FR / DE 16:9 or 9:16 🎬 Model (default Omni Flash) + Kling backend ✎ Short-line handling
3

Write the Dialogue Script

Type or paste what your subject says. Auto-split (on by default) breaks long text into correctly-sized clips automatically. Each numbered line = one clip.

✄ Write like you talk 🔢 Spell out numbers Use contractions
4

Generate

Click 🚀 Start Generation. The platform validates your config, uploads reference frames, and begins processing clips in parallel. Each clip takes 1–3 minutes.

5

Review & Approve Clips

Clips appear as they finish. Watch each one and choose: ✓ Approve to keep, ↻ Redo to regenerate (up to 5 times), or 🗑 Delete to remove. Browse multiple versions with ◀ ▶.

✓ Don't wait for all clips Approve good ones immediately Redo bad ones right away
6

Export

📥 Download All gets each clip as a separate MP4. ✂️ Export Final merges everything into one video with optional frame trimming, silence removal, and audio enhancement. Use ⚡ Speed Up (1.10× recommended) for punchier pacing. Reorder clips with the Lineup Editor before exporting.

⚡ Speed Up (1.01×–1.50×) 🔇 Remove Laughter 🎙️ DeepFilter noise removal 📊 Loudness normalization 📹 Smart Trim ✎ Lineup Editor
Images — Build the Frames First (optional)

The 🖼️ Images tab generates still frames with Google's Nano Banana / Imagen models. Build and approve the images, then promote them straight into a video. Runs on your own browser worker (like the Flow worker, pointed at Nano Banana).

1

Import a Scene Table

On the 🖼️ Images tab click 📋 Import. Paste a markdown scene table — each ### Scene N block becomes one image. Pick a Subject photo (the person in every scene) and an optional Product image. Set the model (Nano Banana 2 default / Pro / Imagen 4), resolution (1K/2K/4K), aspect ratio, and variant count (×1–×4), then click ✨ Create & Generate. Chain scenes with reference_image: image_K or the + Add Parent picker.

📋 One scene = one image 👤 Subject = image 1 📦 Product = image 2 (optional)
2

Start Your Image Worker

In the left ⚙ Worker panel, download the installer (.bat / .command) and run it. Optionally enter the Google email your computer's Chrome is already signed into — the worker reuses that login with no code (BYO). Keep the terminal open while generating.

⬇ Download Installer 🔑 Reuse existing Chrome login (BYO) ⚡ 4 parallel slots recommended
3

Pick the Best Variant

Each scene generates up to four variants. Click the one you like to mark it ✓ chosen. Choosing a frame also unlocks any later scene that references it. Use 📥 Download all for a zip, or ↻ Regenerate failed if some scenes missed.

4

Promote to Video

Once every scene is ready with a chosen variant, click 🎬 Promote to video. The whole batch stages in the Videos tab for a final review, then generates the talking-head video from your approved frames.

Quick Tips
⏳

Always use 8s + Interpolation

The single biggest quality improvement. Natural speech motion needs room. 4s clips often look stiff.

💻

Run 2–4 Chrome Windows

Each window is a parallel worker account. More windows = clips generate side by side = faster jobs.

✅

Review as you go

Don't wait for all clips to finish. Approve good ones and Redo bad ones immediately — redos run in parallel.

✄

Write like you talk

Contractions, natural flow, numbers spelled out. The AI generates from speech patterns — not formal writing.

📷

Good photos matter

Front-facing, well-lit, clean background. The AI focuses on the face — distracting backgrounds reduce quality.

📹

Use Smart Trim on export

Removes static frames between clips while preserving the natural opening of your first clip and scene cuts.

⚡

Speed Up at 1.10×

Barely noticeable but shaves seconds off runtime and makes content feel more energetic. Best default for social media.

📎

Attach Clips to Prompt Jobs

Use "Prompts Only" to create a job, then upload externally generated clips. Voiceover matching auto-assigns them to the right dialogue lines.

🎤

Save Voice Presets

In the ElevenLabs voice panel, save your API key + Voice ID + settings as a named preset. Select from the dropdown on future exports — no re-entry needed.

🖼️

Generate images first

Use the Images tab to build and approve every frame, then Promote to video. You review the look before spending a video render.

✓

Choose variants in order

Chained image scenes wait for their parent's chosen frame. Pick top-to-bottom so each scene builds on an approved one.
